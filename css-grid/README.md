# CSS Grid Project


## Learning Objectives

At the end of this project, you are expected to be able to [explain to anyone](https://fs.blog/feynman-learning-technique/), __without the help of Google__:

- What CSS Grid is and how it enables two-dimensional layout control
- How to create grid containers and define grid structures with rows and columns
- The difference between fixed and flexible sizing in grid layouts
- How to position and span grid items across multiple cells using grid lines
- How to create responsive grids that adapt automatically to available space

<br>

## Requirements
- All your files will be interpreted/compiled on Ubuntu 20.04 LTS using `node 20.x.x` and `npm 10.x.x` or greater
- Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
- A `README.md` file, at the root of the project’s folder and each task’s folder, is mandatory
